## Biến môi trường Vercel
Vào Vercel > Settings > Environment Variables, thêm:

SEPAY_API_KEY = mysecret123
FIREBASE_SERVICE_ACCOUNT = JSON service account Firebase Admin
FIRESTORE_DATABASE_ID = (default) hoặc database id thật của Firebase

Sau đó Redeploy.

## Firebase Google Login OAuth2
Vào Firebase Console > Authentication > Settings > Authorized domains, thêm:

research.vanthemmo.com

Nếu vẫn test trong AI Studio preview thì thêm cả domain dạng:

ais-dev-...run.app

Google Cloud Console > APIs & Services > Credentials > OAuth client Web application:
Authorized JavaScript origins thêm:

https://research.vanthemmo.com

Authorized redirect URIs thêm:

https://research.vanthemmo.com/__/auth/handler
