▣ SePay Thanh toán

Cấu hình tài khoản nhận tiền, tiền tố mã đơn và các gói Pro. Khi SePay báo giao dịch thành công, webhook sẽ nâng cấp Pro và cộng dồn hạn dùng.

Vào SePay → Tích hợp Webhook → Bảo mật → API Key → nhập key tùy ý → copy vào đây.
Ví dụ: sep_live_xxxxxxxxx hoặc chuỗi bí mật tự đặt trong SePay
Mã thanh toán sẽ dạng: RESEARCH + số.
Dán URL này vào SePay để nhận thông báo giao dịch tự động.
Dạng JSON. Có thể đổi giá và số ngày ở đây.
[{"id":"3m","name":"GÓI 3 THÁNG","amount":180000,"days":90},{"id":"6m","name":"GÓI 6 THÁNG","amount":300000,"days":180},{"id":"12m","name":"GÓI 1 NĂM","amount":500000,"days":365}]
Webhook đúng:
GET mở kiểm tra chạy.
POST từ SePay phải có API Key đúng.
Lưu trước khi test:
Nút kiểm tra webhook sẽ tự lưu cấu hình hiện tại rồi mới chạy test.

✉️ Cấu hình Email SMTP

Dùng để gửi email thông báo thanh toán thành công. Gmail cần App Password 16 ký tự, không dùng mật khẩu đăng nhập Gmail thường.

Chuỗi 16 ký tự của Gmail.
Gmail:
Host: smtp.gmail.com
Port SSL: 465
Port TLS: 587
Luồng tự động:
SePay thành công → nâng cấp Pro → cộng dồn hạn → gửi email.

Hướng dẫn lấy App Password Gmail

  1. Vào tài khoản Google → Bảo mật.
  2. Bật xác minh 2 bước.
  3. Vào App passwords / Mật khẩu ứng dụng.
  4. Tạo mật khẩu cho ứng dụng Mail.
  5. Copy chuỗi 16 ký tự dán vào ô App Password Gmail.

Hướng dẫn kiểm tra webhook đúng

  1. Nhập đúng Webhook Secret giống API Key trong SePay.
  2. Bấm Lưu & kiểm tra webhook.
  3. Nếu thành công, trang sẽ báo webhook đã nhận POST test với secret đang lưu.
