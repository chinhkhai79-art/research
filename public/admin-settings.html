⚙️ Cấu hình thanh toán & SMTP

Quản lý SePay, thông tin ngân hàng, webhook và email gửi thông báo thanh toán thành công.
/admin-settings.html
Bảo mật: không dán Webhook Secret, App Password Gmail vào code công khai. Trang này lưu cấu hình vào Firestore qua serverless API. Đặt biến môi trường ADMIN_SETTINGS_PASSWORD trên Vercel để bảo vệ trang.

🔐 Đăng nhập quản trị

Trình duyệt chỉ giữ tạm bằng localStorage để tiện thao tác.

▣ SePay Thanh toán

Vào SePay → Tích hợp Webhook → Bảo mật → chọn API Key → nhập key tùy ý → copy vào đây.
Ví dụ: sep_live_xxxxxxxxx hoặc chuỗi bí mật anh tự đặt trong SePay
Nội dung thanh toán sẽ có dạng: RESEARCH + mã đơn.
Copy URL này dán vào SePay để nhận thông báo giao dịch tự động.
Dạng JSON. Có thể đổi giá và số ngày ở đây.
Ví dụ: [{"id":"3m","name":"Gói 3 tháng","amount":180000,"days":90},{"id":"6m","name":"Gói 6 tháng","amount":300000,"days":180},{"id":"1y","name":"Gói 1 năm","amount":500000,"days":365}]

✉️ Cấu hình Email SMTP

Dùng App Password 16 ký tự của Gmail, không dùng mật khẩu đăng nhập Gmail thường.

Hướng dẫn lấy App Password Gmail

  1. Vào tài khoản Google → Bảo mật.
  2. Bật xác minh 2 bước.
  3. Vào App passwords / Mật khẩu ứng dụng.
  4. Tạo mật khẩu cho ứng dụng Mail.
  5. Copy chuỗi 16 ký tự dán vào ô App Password Gmail.
